# 從 Chat 到 Work：好的 AI 系統，是把摩擦力放對地方

AI 真正該省的不是工作量，是這些卡住的地方。摩擦分三種，只有一種該全部交給 AI。

## 閱讀

- 網頁版：https://weber-yuan.github.io/friction-in-the-right-place/
- Markdown 原文：[article.md](./article.md)

## 內容摘要

| 摩擦類型 | 特徵 | 怎麼處理 |
| --- | --- | --- |
| 低價值摩擦 | 重複、可逆、只是搬運與轉換 | 盡量交給 AI |
| 治理摩擦 | 高風險、不可逆、涉及金錢與責任 | 刻意增加 |
| 有意義的摩擦 | 關乎理解、創造、學習與判斷力 | 主動保留 |
